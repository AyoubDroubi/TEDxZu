# TEDx GitHub Repository Vault

The following repositories represent the highest-quality open-source implementations for TEDx event websites, spanning modern frameworks like **Next.js**, **React**, and **Django**, alongside robust static templates optimized for rapid deployment.

## 1. TEDxNTUA (National Technical University of Athens)
- **Repository URL:** [https://github.com/TEDxNTUA](https://github.com/TEDxNTUA)
- **Deployment/Clone Command:** ```bash
  git clone https://github.com/TEDxNTUA/tedxntua2023.git
  cd tedxntua2023
  ```
- **Architecture Breakdown:**
  - **Tech Stack:** Django (Python), PostgreSQL, Alpine.js, Tailwind CSS.
  - **Features:** Multi-year support, dynamic speaker management, integrated ticketing portal, and an advanced administrative dashboard for content editors.
  - **Responsiveness:** 10/10; utilizes a mobile-first design pattern.
  - **Customization Difficulty:** Moderate (requires Django knowledge).

## 2. TEDxVITVellore 2021
- **Repository URL:** [https://github.com/TEDxVITVellore/TEDxVITVellore-2021](https://github.com/TEDxVITVellore/TEDxVITVellore-2021)
- **Deployment/Clone Command:** ```bash
  git clone https://github.com/TEDxVITVellore/TEDxVITVellore-2021.git
  cd TEDxVITVellore-2021
  npm install
  ```
- **Architecture Breakdown:**
  - **Tech Stack:** Next.js (React), Tailwind CSS, Framer Motion.
  - **Features:** High-performance Server-Side Rendering (SSR), complex SVG animations, and a sophisticated speaker grid with interactive modal states.
  - **Responsiveness:** High; optimized for all device breakpoints.
  - **Customization Difficulty:** Low (for React developers).
